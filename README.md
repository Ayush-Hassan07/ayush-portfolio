# Ayush Hassan Raiyan — Portfolio

A production-grade, content-driven portfolio platform for software engineering, AI systems, research, and cybersecurity.

## Status

Under active development.

## Technology

- Next.js
- TypeScript
- React
- NestJS
- PostgreSQL
- Prisma
- Python / FastAPI
- Docker
- Cloudflare

## Architecture

The project is designed as a modular monorepo containing:

- Public portfolio application
- Administrative CMS
- Backend API
- PostgreSQL database
- AI services
- Shared packages
- Deployment and infrastructure configuration

## Development

Development setup and project documentation will be added as the platform is implemented.

## Security

Secrets, credentials, API keys, database passwords, and other sensitive configuration must never be committed to the repository.
